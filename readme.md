# Library Management System (Flask)

A full-stack web application built using Flask and SQLite for managing books in a library.

## Features
- User login system
- Add / Edit / Delete books
- Search books
- Issue and return books
- Automatic return date calculation
- Bootstrap UI

## Tech Stack
- Python (Flask)
- SQLite
- HTML, Bootstrap

## How to Run
1. Install requirements:
   pip install flask

2. Run app:
   python app.py

3. Open:
   http://127.0.0.1:5000
